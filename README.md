# 🏋️‍♂️ To-Do List de Atividades Físicas - User Stories

Este documento reúne o mapeamento de **User Stories** para o desenvolvimento de um aplicativo de lista de tarefas focado em saúde, treinos e atividades físicas. O formato segue o padrão ágil estabelecido para o projeto.

---

## 📋 Formato Padrão utilizado
* **Como** [papel/persona]
* **Quero** [ação/funcionalidade]
* **Para** [benefício/motivo]

---

## 🎯 1. Planejamento e Organização

### User Story 1: Treinos Recorrentes
* **Como** um praticante de musculação recorrente
* **Quero** cadastrar treinos repetitivos para dias específicos da semana
* **Para** não precisar reescrever a mesma lista de exercícios toda vez.

### User Story 2: Metas de Longo Prazo
* **Como** um corredor de rua amador
* **Quero** agendar metas de quilometragem semanal na minha lista
* **Para** acompanhar visualmente o meu progresso ao longo do mês.

### User Story 3: Priorização de Atividades
* **Como** alguém com a rotina muito corrida
* **Quero** definir níveis de prioridade (alta, média, baixa) para cada atividade física do dia
* **Para** focar primeiro nos treinos essenciais caso falte tempo.

---

## 🔥 2. Execução e Motivação

### User Story 4: Conclusão Rápida em Treino
* **Como** um usuário que treina ouvindo música
* **Quero** marcar um exercício como concluído diretamente pela tela de bloqueio ou por comando de voz
* **Para** não quebrar o ritmo da minha atividade tirando o celular do bolso.

### User Story 5: Lembretes Ativos
* **Como** uma pessoa que se esquece de beber água ou alongar
* **Quero** receber notificações de lembrete com base no horário planejado
* **Para** manter a consistência e o foco no hábito saudável.

### User Story 6: Recordes Pessoais (PR)
* **Como** um atleta competitivo
* **Quero** registrar marcas pessoais (como carga máxima ou menor tempo de corrida) ao concluir uma tarefa
* **Para** monitorar minha evolução de desempenho de forma integrada.

---

## 📊 3. Histórico e Gamificação

### User Story 7: Sistema de Ofensivas (Streaks)
* **Como** um usuário focado em criar novos hábitos
* **Quero** visualizar um contador de dias seguidos em que cumpri minhas metas físicas
* **Para** me manter motivado a não quebrar a sequência.

### User Story 8: Gráficos de Desempenho
* **Como** alguém que gosta de analisar dados de saúde
* **Quero** acessar um gráfico de pizza que mostre a divisão dos tipos de atividades concluídas (Ex: Cardio vs. Força)
* **Para** entender se estou equilibrando meus treinos corretamente.

---

## 👥 4. Compartilhamento e Ajustes

### User Story 9: Integração Social
* **Como** parte de um grupo de amigos que treinam juntos
* **Quero** compartilhar minha lista de atividades ou desafios concluídos nas redes sociais
* **Para** incentivar outras pessoas e celebrar minhas conquistas cotidianas.

### User Story 10: Reagendamento Flexível
* **Como** um usuário que teve um imprevisto de última hora
* **Quero** adiar uma atividade pendente para o dia seguinte com apenas um clique
* **Para** não perder o registro da meta, apenas reorganizar o meu calendário.
